# GitHub profile package

The finished profile is `README.md`. Its custom banner is `assets/kervcodes-banner.svg`.

## Put it on your profile

Your profile repository is `kervcodes/kervcodes`; an existing README was found there.

1. Replace that repository's root `README.md` with the README in this package.
2. Upload the `assets` folder alongside it, preserving the folder name.
3. Commit both files together. The relative banner path will resolve inside the repository.

The ZIP contains this same folder structure. Extract it before uploading the files.

## Design

Dark navy, lime, and cyan; a custom SVG hero; two featured project cards; a compact stack; and a clear invitation to connect. The profile uses GitHub-compatible Markdown and HTML. All graphics are stored with the repository, without external image-service dependencies.

No tokens, scheduled workflows, or statistics services are required. No edits have been published to GitHub.
